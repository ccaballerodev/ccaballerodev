### SmartSensors

**Plataforma de monitoreo agrícola IoT**

Plataforma que integra sensores de suelo y aire con una aplicación web para consultar mediciones, evaluar la compatibilidad de cultivos y obtener recomendaciones agrícolas. Incluye un asistente conversacional con inteligencia artificial que utiliza los datos de los sensores para contextualizar sus respuestas.

- Desarrollo de una API REST con Flask y MongoDB Atlas.
- Implementación de una interfaz web con React, TypeScript y Vite.
- Integración de un asistente conversacional mediante n8n y modelos de lenguaje.
- Gestión de sensores, mediciones, usuarios, dispositivos y calificaciones.

**Tecnologías:** Python, Flask, MongoDB Atlas, React, TypeScript, Vite, Tailwind CSS, n8n.
